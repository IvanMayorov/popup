Popup

Простой попап для статей, карточек и форм. Окно растёт с содержимым, а прокручивается весь слой, как обычная страница. Крестик едет вместе с прокруткой.

  • ~4 КБ JS
  • Esc и клик по фону
  • Фокус и inert
  • Светлая и тёмная тема
Показать код

Закрыть: крестик, Esc или клик по фону

<!-- Подключение -->
<link rel="stylesheet" href="popup.css">
<script src="popup.js"></script>

// Открыть
const p = Popup.open({
  content: "<h2>Привет</h2><p>Любой HTML или DOM-элемент</p>",
  label: "Привет",   // название окна для экранных дикторов
  wide: false,       // true — широкое окно
  onClose() {},
});
p.close();          // закрыть из кода
Popup.closeAll();   // закрыть все

Что умеет

  • Скролл всего слояОкно уходит за нижний край, сразу видно, что дальше есть текст.
  • Липкий крестикЗакрыть можно с любого места длинной статьи.
  • Скролл не застреваетПосле конца внутреннего блока колесо крутит окно дальше.
  • Сайт стоит на местеСтраница под попапом недоступна и не прокручивается.
  • Попапы стопкойНижний отъезжает назад, Esc закрывает верхний, фокус возвращается.
  • Сайт не прыгаетВместо пропавшей полосы прокрутки добавляется такой же отступ.
  • Лёгкая анимация180 мс на появление, 120 мс на исчезание, учитывает «Уменьшить движение».
