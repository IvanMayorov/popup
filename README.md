# Popup

Простой попап без зависимостей и без анимации. Подходит для статей, карточек, форм: всё, что нужно показать поверх страницы.

Демо: https://ivanmayorov.github.io/popup/

Вырос из попапа проекта Rocket и попапа статей на сайте курса «Вайбдизайнер».

## Что умеет

- Закрывается крестиком, клавишей Esc, кликом по фону и любым элементом с атрибутом `data-popup-close`.
- Пока попап открыт, остальная страница недоступна и не прокручивается.
- Попапы можно открывать друг поверх друга, Esc закрывает верхний.
- После закрытия фокус возвращается на кнопку, которая открыла попап.
- На телефоне раскрывается на весь экран.
- Светлая и тёмная тема, цвета и размеры меняются через CSS-переменные.

## Как подключить

```html
<link rel="stylesheet" href="popup.css">
<script src="popup.js"></script>
<script>
  const p = Popup.open({
    content: "<h2>Привет</h2><p>Любой HTML или DOM-элемент</p>",
    label: "Привет",       // название окна для экранных дикторов
    wide: false,           // true — широкое окно, например для схем
    onClose() { /* что сделать после закрытия */ },
  });
  // p.close() — закрыть из кода, Popup.closeAll() — закрыть все
</script>
```

Пример лежит в `index.html`: откройте его в браузере.

## Как попросить агента

«Подключи к сайту попап из github.com/IvanMayorov/popup и открывай в нём <что именно>.»

## Настройка

Переопределите переменные в своём CSS:

```css
:root {
  --popup-bg: #fff;
  --popup-radius: 20px;
  --popup-width: 820px;
  --popup-shade: rgb(26 28 33 / 0.5);
}
```
